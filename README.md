# Actividad Evaluativa: Web Components, HTML Templates y Frameworks

- **Integrantes:** Diego Rosas y Daniel Tapias
- **Caso elegido (Práctica):** Plato del menú de un restaurante (Nombre, precio, disponibilidad, con slot para ingredientes/nota).
- **Cómo probar el componente:**
  1. Clona o descarga este repositorio.
  2. Abre el archivo `index.html` en un navegador web moderno (Chrome, Edge, Firefox).
  3. Visualiza las 3 instancias del componente personalizado `<menu-plato>` con sus respectivos atributos, estilos y slots.
  4. Abre la consola del navegador (`F12` o `Ctrl+Shift+I`) para verificar que no hay errores y que todo funciona correctamente.
- **Declaración de uso de IA:** Se empleó inteligencia artificial como herramienta de apoyo y consulta conceptual para estructurar la investigación técnica, validar la sintaxis de los Custom Elements con Shadow DOM y organizar de manera limpia los requerimientos del código base. Todo el contenido fue revisado, adaptado y verificado por los integrantes del equipo.
